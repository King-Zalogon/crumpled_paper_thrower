# crumpled_paper_thrower

A personal **candidate list of Argentine real-estate agency homepage URLs**, used
by a personal property-watching project to keep track of which agencies have
already been noted — across any conversation or machine.

`agencies.txt` is the only data file: a flat, alphabetically sorted list of
homepage URLs, one per line, normalized (always `https://`, no `www.`, no
trailing slash). **That is all it is.**

It deliberately contains **nothing else** — no scraped listing data, no agency
names or contact information, no platform or scrapability evaluation, and no
guarantee that any listed site is usable. A URL appearing here means only *"this
is a real-estate agency's own homepage that has been noted"* — nothing about
whether it can or should be scraped. All evaluation, platform detection, and
usage decisions live in the separate private project, not here.
